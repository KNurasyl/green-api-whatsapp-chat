# WhatsApp Chat

Тестовое задание GREEN-API: веб-чат для личных текстовых сообщений WhatsApp.

Сейчас готова основа проекта: React, TypeScript, Vite, ESLint и Vitest. Подключение к GREEN-API и обмен сообщениями будут добавлены следующими этапами.

## Запуск

Нужен Node.js 24. Зависимости устанавливаются из lock-файла:

```bash
npm ci
npm run dev
```

Vite выводит адрес приложения в терминале. По умолчанию это http://localhost:5173.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запустить разработку |
| `npm run typecheck` | Проверить типы |
| `npm run lint` | Проверить код |
| `npm test` | Запустить тесты |
| `npm run build` | Проверить типы и собрать приложение в dist |
| `npm run preview` | Открыть готовую сборку локально |

Тесты появятся вместе с логикой чатов. Пока тестовых файлов нет, Vitest сообщает об этом и завершает `npm test` с кодом 1.

## Структура

Вход в приложение — `src/main.tsx`, стартовый экран — `src/App.tsx`, общие стили — `src/styles.css`. Модули API, чатов и уведомлений добавляются по мере реализации.

В `.env.example` предусмотрен `VITE_GREEN_API_URL` для адреса API из кабинета GREEN-API. Токен будет вводиться в интерфейсе и храниться в памяти страницы.
