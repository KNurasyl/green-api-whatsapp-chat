# WhatsApp Chat

Тестовое задание GREEN-API: веб-чат для личных текстовых сообщений WhatsApp.

Сейчас готова основа проекта: React, TypeScript, Vite, ESLint, Prettier и Vitest. Подключение к GREEN-API и обмен сообщениями будут добавлены следующими этапами.

## Запуск

Нужен Node.js 24. Зависимости устанавливаются из lock-файла:

```bash
npm ci
npm run dev
```

Vite выводит адрес приложения в терминале. По умолчанию это http://localhost:5173.

## Команды

| Команда                | Назначение                                                      |
| ---------------------- | --------------------------------------------------------------- |
| `npm run dev`          | Запустить разработку                                            |
| `npm run typecheck`    | Проверить типы                                                  |
| `npm run lint`         | Проверить код                                                   |
| `npm run lint:fix`     | Исправить ошибки, которые линтер умеет исправлять автоматически |
| `npm run format`       | Отформатировать файлы                                           |
| `npm run format:check` | Проверить форматирование без изменения файлов                   |
| `npm run check`        | Проверить форматирование, линтер и типы                         |
| `npm test`             | Запустить тесты                                                 |
| `npm run build`        | Проверить типы и собрать приложение в dist                      |
| `npm run preview`      | Открыть готовую сборку локально                                 |

Тесты появятся вместе с логикой чатов. Пока тестовых файлов нет, Vitest сообщает об этом и завершает `npm test` с кодом 1.

## Стиль кода

Prettier отвечает за форматирование: два пробела, одинарные кавычки, без точек с запятой, ширина строки 100 символов и окончания строк LF. ESLint проверяет JavaScript, TypeScript, правила хуков и Fast Refresh. Для TypeScript включена проверка с учётом типов: она находит необработанные Promise и небезопасное использование данных.

Настройки Prettier и ESLint согласованы через eslint-config-prettier. Исходники и конфигурация пишутся без комментариев; объяснения остаются в README.

Для VS Code и Cursor добавлены настройки сохранения и рекомендации расширений. Установите рекомендованные ESLint, Prettier и EditorConfig, если редактор ещё не использует их. При сохранении файла запускаются Prettier и доступные исправления ESLint.

После `npm ci` Husky автоматически подключает локальный pre-commit hook. Перед коммитом lint-staged исправляет и проверяет добавленные в индекс файлы, затем запускается проверка типов проекта. Неисправленная ошибка останавливает коммит. Сборка, зависимости, секреты и lock-файл исключены из форматирования; lock-файл обновляет npm.

Перед завершением этапа выполните `npm run check` и `npm run build`, а после появления тестов — также `npm test`.

## Структура

Вход в приложение — `src/main.tsx`, стартовый экран — `src/App.tsx`, общие стили — `src/styles.css`. Модули API, чатов и уведомлений добавляются по мере реализации.

В `.env.example` предусмотрен `VITE_GREEN_API_URL` для адреса API из кабинета GREEN-API. Токен будет вводиться в интерфейсе и храниться в памяти страницы.
